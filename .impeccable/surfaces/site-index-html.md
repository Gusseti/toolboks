# Landing page (site/index.html)

Mode: persuade. Audience: curious Windows users (primary), add-on authors (secondary). Action: download toolboks.exe from the latest GitHub release. Proof: the working window itself, the real add-on list, the real verification mechanism, the real SDK manifest. Constraints: DESIGN.md is binding (graphite, one purple accent, Segoe UI Variable system stack, no glow, gradients, glass, uppercase labels, eyebrows, emoji); no invented numbers, testimonials or online-catalog claims.

## Direction contract

THESIS: The page is the Toolboks window, seen once and at full scale; the visitor installs and removes add-ons and watches the platform recompose. It refuses the split hero (copy left, screenshot right, badge row below) and the feature-card grid.

OWN-WORLD: Graphite window #0e0f11 framed by #0a0b0c title bar, sidebar and status bar; hairline #24262c cards; one purple accent #8b5cf6 for selection, switches and the verified seal; data colours only beside labels. Authored 1.7 px stroke icons. Segoe UI Variable, sentence case, tabular numbers.

STORY: Toolboks is a frame; tools are add-ons I choose. First-party ones are verified by the app itself, every install shows its access, and anyone can build one. I download it.

FIRST VIEWPORT: A full-width Toolboks window. Title bar carries the mark, links and the Download button. Sidebar lists installed add-ons. Workspace "Toolboks / Home": headline "One window. The tools you choose." at ~64px, sub-line, Download, then the add-on browser list with switches. Status bar live.

FORM: Live window, your tools; position 3 of 7 on my list. seed:e0b32c951b0ab85a (degraded roll, no challengers).
Signature interaction: toggling an add-on slides it into or out of the sidebar and status bar; clicking a sidebar entry swaps the workspace to that tool's live demo. Motion grammar: 150-220 ms exponential ease-out, state changes only; graphs tick at 1 Hz; reduced motion freezes ticks.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
