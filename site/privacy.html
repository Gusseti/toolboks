Privacy policy

Toolboks does not collect data. There are no accounts, no analytics, no telemetry and no ads, and we run no server that could receive anything from the app.

Last updated 15 November 2026. Covers the Toolboks app and this website.

What stays on your PC

Toolboks reads information about your system so it can show it to you: running programs, memory, drives, network connections, Windows events and settings. All of it is read, shown and kept on your PC. None of it is sent anywhere.

Your preferences, profiles, macros and undo history are saved in a local data folder. Deleting that folder removes them.

When Toolboks connects to the internet

This is the complete list. Each request only asks for a file or a page. It carries no information about you, your PC or how you use Toolboks.

Update check

Once when the app starts, and when you press Check for updates, Toolboks asks GitHub which version is the latest. This is the only connection made without you asking for it.

What GitHub sees

Toolboks and its add-ons are downloaded from GitHub. Like any web server, GitHub sees the IP address a request comes from, the time, and the program name “toolboks”. GitHub handles that under its own privacy statement. We cannot see it.

GitHub shows us one number per file: how many times it has been downloaded in total. Download counts shown for Toolboks or for add-ons come from that public total. It does not tell us who downloaded anything.

Add-ons

Add-ons are separate programs that run inside the Toolboks window. Tools with the Toolboks verified mark are made by the Toolboks team and follow this policy. An add-on from anyone else is the responsibility of its author, so read what it says about your data before you install it.

This website

This site has no cookies, no analytics and no forms. It is hosted on GitHub Pages, so GitHub sees your IP address when you visit. The fonts are loaded from Google Fonts, so Google sees your IP address when the page loads them.

Code signing statement

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The one automatic connection is the update check described above, which sends no information about you or your PC.

Changes and questions

Because we hold no data about you, there is nothing for us to show, correct or delete. If Toolboks ever starts to collect anything, this page will say so first, and the change will be listed in the changelog.

Toolboks is open source, so you can check all of this in the source code. Questions go to the issue tracker.
